# Typography, Punctuation & Documentation Rules

## Punctuation Standards
- **Never use the em-dash character (`—`)** anywhere in the code, comments, documentation, markdown, HTML, or responses.
- **Always use the standard ASCII hyphen (`-`)** with appropriate spacing (e.g., ` - `) instead of any em-dash or en-dash.

## Formal Documentation Standards
- **Do not use emojis/icons in `README.md` or formal project documentation headings and lists.** Keep all documentation text clean, formal, academic, and executive.
